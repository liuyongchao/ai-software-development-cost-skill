# 给定参数的模型任务方程演算

## R — 原文

> 示例：假设基于基准数据建立的单个任务包工作量回归方程如下：TEi = TBEi×TFi×SRi×TSi×SF×MRDF。

出处：6.3.3.2 a)，式5，PDF第18页；参数与范围说明见6.3.3.1–6.3.3.2，PDF第17–20页。

## I — 自述

式5是正文给出的假设方程，本卡只执行项目明确选择的该情景。  
先确认一个工作包交付什么、基准覆盖什么，再代入已确认适用的参数。  
TBE给出基准工时，TF表示该任务的局部影响，两者均需来源。  
SR只保留外包及复用之后的自研部分，TS表示工具支持造成的工时调整。  
SF和MRDF描述全局影响，进入每个任务计算一次。  
缺TF等任一因子就保留缺项，不用1或附录中值填空。  
结果证明给定输入的乘法成立，不证明假设方程已被回归验证或适合真实报价。

## A1 — 应用示例

书中例题：附录E.2.3.2.1，PDF第50页。模型搭建任务设TBE=16人天、TF=1、SR=0.67、TS=1、SF1=1.5、SF2=1.15、MRDF1=1、MRDF2=0.9。先组装SF=1.725、MRDF=0.9，再算16×1×0.67×1×1.725×0.9=16.6428人天，显示约16.64人天。

这是例题既定参数的复算；原书没有完整展开各档位适用证据，实际完工结果未说明。不能把16人天、0.67或其他例题数值带入新项目。若新输入漏TF，停止该项数值计算并索取适用TF及来源，不能由此例默认TF=1。

## A2 — 未来触发

- 已选式5且参数齐全：“帮我复算这个模型工作包。”／task effort, formula 5。
- 报价隐去某个因子：“没有TF能不能先按1算？”／missing factor, baseline effort。
- 复用与工具节省同时出现：“SR和TS怎么进入计算？”／self-developed ratio, tool support。
- 需要核对假设与结果：“这个回归方程已经验证了吗？”／hypothetical model, scenario calculation。

区别：本卡计算单工作包；“模型全局因素组装与重复应用检查”提供SF与MRDF及使用位置；“模型任务工时与岗位费用汇总”接收TE后按岗位计费。本卡不从附录自动选择基准或系数。

## E — 执行

输入契约：必填任务ID、范围/交付物、采用正文式5的明确选择记录、TBE数值及人时/人天/人月单位、TF/SR/TS/SF/MRDF数值、每项来源版本与适用性说明、基准是否已调整、外包/复用扣减记录。除TBE外因子无量纲；SR为0至1的自研比例，其他因子须有适用取值依据，不据表格自动补值。缺关键值、单位或适用依据时仅出待补单。

1. 核范围与方程选择：排除数据处理、主体功能及重复工作，确认TBE与本任务粒度一致。未明确选择假设式5则停止本卡计算。完成标准：任务、基准和方程采用依据能相互对应。
2. 核六项输入及调整顺序。TF若来自多个局部因素，须附已确认组合规则；遇提示词或编排的冲突参数，先补采用版本/依据。SR已扣外包或复用后，不再扣相同工时；SF/MRDF已含子因子时不重复展开。完成标准：不存在缺值、混用版本、隐含默认1或重复调整。
3. 按TE=TBE×TF×SR×TS×SF×MRDF逐项计算，保留代入式和未舍入值。若合法SR=0，记录相应自研为0的依据，仍保留外购服务接口。完成标准：输出单位与TBE一致，所有因子可回查且各使用一次。
4. 输出任务ID、公式选择标签、参数/来源表、完整乘积、TE、单位、外包处理状态和适用性限制。实现约定：中间不舍入，展示人天至2位，小数精度不同须声明；复核展示值容差为半个末位，不掩盖参数差异。完成标准：另一个人可复算，明确这是选定假设情景。

计算前先读 `calculator-guide.md`，按其接口填写 `project-template.json`，再使用 `cost_calculator.py`；人工确认适用性不能由脚本通过替代。

## B — 边界

附录D只是参考，不自动映射任务或档位。提示词系数、编排范围等存在冲突时不得静默挑值；评分全0使TF=1也不能证明冲突已消失。已调整TE求和后不再乘全局因子。缺任务基准不等于该工作免费，算术正确也不构成预测效度证明。
