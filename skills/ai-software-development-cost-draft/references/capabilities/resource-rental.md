# 资源租赁单价与期间费用计算

## R — 原文

> OMUP——租赁期内的资源运维单价，需扣除免费服务期后计算资源运维单价。市场询价时，需获取不少于三家单位的正式报价，可在剔除异常数据后选取中值作为参考价格。

出处：7.2.1式9及7.2.3 d)，PDF第23页；免费资源见PDF第24页，数据安全与到期迁移见4.3.2.2 d)，PDF第10页。

## I — 自述

先核资源取得方式和开发期间，再决定是否有应计租赁费用。  
免费、利旧、统采等已覆盖的资源，不因市场上有租价就另计费用。  
单价、数量和租赁期必须使用相同计量及时间口径。  
市场询价要至少三家正式可比报价；指导价、历史合同和方程法另核各自依据。  
式9涉及年折旧，运维单价应扣免费期并对齐期间，不能直接叠加全年与全租期金额。  
按月均摊必须有项目约定，不能从折旧公式自行推出租赁计费政策。  
安全要求和到期迁移安排也需留证，但不能因此把交付后运维混入开发成本。

## A1 — 应用示例

原书未提供完整租赁数值案例。合成演练：2台资源租6个月，UP=120000元/台、CC=0元/台、DL=5年、已扣免费服务期的OMUP=6000元/台年；题设明确采用12月均摊且无其他收费。年单价=(120000+0)÷5+6000=30000元/台年，月单价2500元/台月，费用=2500×2×6=30000元。另1台已确认免费利旧资源，另计租赁费为0。

这是给定口径的演算，真实租赁结果未说明；题设未提供安全和到期迁移材料，仍须列待补。仅有两家正式市场报价的变体不满足询价要求；采用适用地方指导价时，不额外强制三家报价。

## A2 — 未来触发

- 云资源或设备按时段租用：“开发期租六个月多少钱？”／resource rental, rental period。
- 需要从购置成本推租价：“折旧年限和运维费怎么算？”／depreciation, financing cost。
- 已有资源又出现租价：“免费或统采资源能再收租金吗？”／free resources, duplicate rental。
- 比选租赁方案或检查合同：“免费期、到期迁移是否算清？”／free service period, data migration。

与“费用归类与重复列支检查”的区别：归类先界定取得方式及重复权利，本卡再审核租价来源、期间及算术；购买所有权的询价使用采购能力。

## E — 执行

输入契约：必填资源ID、类型/配置/地域/用途/服务、取得方式、数量及单位、开发起止与交付日、租赁起止/付费期/计费规则、RUP及货币/每资源每期间单位、取价路径和证据。方程法另需UP、CC及地方政策依据、DL年数、OMUP金额与期间、免费服务期及扣减记录。还需业务数据安全要求、合同到期迁移责任/安排和成本依据；未知单列待补，不填零。

1. 核资源权利及期间：开源就绪软件、利旧、统采或免费提供的适用资源不另计租赁，采购与租赁同权利排重；截取开发期范围，交付后租赁另归运维。完成标准：每项有纳入、排除或待确认理由，免费0有证据。
2. 按路径查取价。指导价核核心属性、地域和版本；历史成交核可比合同；地方指导价、本单位成交及近一年案例的“宜”要求作为核查项，未采用须留理由。市场询价须至少三家正式可比报价并形成记录；两家则暂停该路径。异常剔除须有证据，中值采用依据及偶数定义须明确。完成标准：所选路径证据齐备，不互套门槛。
3. 方程法算RUP=(UP+CC)÷DL+OMUP。先将运维免费服务期扣净，再确认折旧部分与OMUP同期间；DL以年计时得到的年度分摊不能直接与整租期运维费相加。月价换算须有明确项目约定，缺口径则停止。完成标准：资金成本、折旧及运维各有来源，单位全部对齐。
4. 按同一计费期间算RRF=Σ(RUPi×Ni×LTi)。阶梯价、免费租期或不满期计费按已确认合同规则分段，不自行线性外推。完成标准：数量/期间不重计，免费运维未再收费；免费租期与免费运维期分别检查。
5. 核安全要求、到期迁移方案/责任/成本依据及发生时点；未知列待补，不凭风险加一个比例，也不把交付后费用纳入开发小计。输出询价记录及机房柜、软硬件、云服务/链路明细，含路径、单价、数量、期间、免费扣减、金额、证据和完整性状态。实现约定：中间不舍入，金额显示至货币最小单位，展示复核容差半个末位。完成标准：数值可复算，已知金额与合同缺项清楚区分。

调用前先读 `calculator-guide.md`，再按其说明使用 `project-template.json`和 `cost_calculator.py`；不得猜测脚本字段或把算术通过当作合同完整。

## B — 边界

不自动指定折旧年限、资金利率、12月均摊或免费期；真实计费以已确认依据为准。至少三家仅约束市场询价。缺单价、期间或必要换算不能输出完整费用；只有安全/迁移材料待补时可保留已算情景值，同时明确评估未完整。不得把已有资源等价市场价当作新增租赁支出。
