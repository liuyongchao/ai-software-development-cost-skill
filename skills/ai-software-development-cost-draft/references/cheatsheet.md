# 决策规则速查 — 系统与软件工程 人工智能应用软件开发成本度量（2026-08-18征求意见稿）

| 能力 | 一句话规则 |
|---|---|
| 开发成本适用范围判定 | 按应用开发目的和启动至交付时段逐活动给出纳入、排除或待确认理由。 |
| 费用归类与重复列支检查 | 把实际工作按三类综合人力和六类直接非人力分类；用承担方、资源取得方式、期间和交付物核对重计。 |
| 工作分解、成果与估算方法矩阵 | 按需求把主体、数据、模型及非人力工作列成任务—成果—验收—方法—证据矩阵；数据任务明确类型、规模、质量、成果与交付周期；检查测试和管理分摊。 |
| 主体功能测算接口与计费口径复核 | 输出主体功能范围、外部标准版本、规模/生产率/调整/费率/单位接口及重计检查。 |
| 数据计件与样本单位工时测算 | 对可量化且效率稳定的任务，使用已有适用单位工时，或以代表样本总人时除同口径样本件数确定单位工时，再乘待处理规模；记录人工作业/自动化和质检返工范围。 |
| 数据基准工时与复用工具因素计算 | 在基准粒度和适用性已确认时，计算DBE×AF×DRDF；若声明DRDF由DR与DDT组成则乘这两项。 |
| 数据任务岗位费用汇总 | 排重后统一工时单位；逐任务按DPE×PF×UHC计费，再合计工时和费用。 |
| 独立传统模型数量判定 | 检查目标、业务规则与判定逻辑、单独采集标注训练三组条件；同一识别任务多站点部署排重。 |
| 独立智能体与内部节点判定 | 逐对象同时核对三组条件：独立业务入口/界面/API（本组入口形式为或）；独立知识库、提示词、编排逻辑与业务规则；独立部署、启停、交付并完成业务目标。逐项留证。 |
| 给定参数的模型任务方程演算 | 明确选择正文式5假设模型且给定适用参数后，计算TBE×TF×SR×TS×SF×MRDF并记录因子来源。 |
| 模型全局因素组装与重复应用检查 | 在业务/质量/团队/成熟度因子分别有依据时计算SF1×SF2、MRDF1×MRDF2，标记其作用层。 |
| 模型任务工时与岗位费用汇总 | 对已排除外包、数据和主体功能重叠的任务，汇总TE并逐岗位计算TE×PF×UHC。 |
| 专用软硬件采购询价复核 | 统一规格、授权、税费/服务边界，保存至少三家正式可比报价；有依据时选中值作为参考。 |
| 资源租赁单价与期间费用计算 | 核取得方式和开发期间，按同一计费期间计算Σ单价×数量×期间。选市场询价路径时需至少三家正式可比报价与记录；指导价、历史合同或方程路径不机械套三家。地方/本单位/近一年等原稿“宜”要求作为核查项。成本方程明确折旧年限、资金成本、扣免费期后的同期间运维。另记录业务数据安全要求、合同到期迁移安排及成本依据；未知列待补，不因此把交付后运维计入开发成本。 |
| 基础设施集成估算与边界检查 | 确认专用基础设施范围；比例法用明确外部基数/费率/系数逐项计算，经验法用人员级别和分步工时/工具费。 |
| 外购数据资源与服务取价 | 按具体数据/服务、授权、质量、期间形成询价与可比成交记录，计开发期第三方费用并排除同活动内部人力。 |
| 外购模型服务授权与用量计价 | 确认授权/API、期间、计费量纲与套餐超额规则；至少三家正式报价；内部被替代工作同步扣除。 |
| 其他直接非人力费用明细评估 | 限定开发期明确产品/服务，依据经委托方确认的业务要求选择经验、类推或方程依据并列明细。 |
| 多方法偏差复核与有条件合成 | 同范围单位比对多方法结果。数据工作量及费用按给定合理偏差判据检查，范围内才按给定权重平均；超范围回查重估。整体或模型费用差异较大时可整理专家评审材料，不把数据加权规则泛化。 |
| 费用区间汇总与完整性声明 | 三类人力、六类非人力逐行保存下/中/上限、单位、来源、已确认零/缺失状态；汇总已知项并列完整性与外部报告依赖。 |
| 参数来源、适用性与更新准备登记 | 登记参数名称、单位、作用范围/粒度、来源/版本、样本范围、适用证据、校正与更新记录；识别参考/已确认/待核状态。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
